# Schooling_System

## Run Project
1. Go to backend:
   ```bash
   cd Backend
   ```
2. Install packages:
   ```bash
   npm install
   ```
3. Start backend & frontend:
   ```bash
   npm start
   ```
4. Open your browser:
   ```text
   http://localhost:5000
   ```
