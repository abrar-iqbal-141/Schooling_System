# Schooling_System

## Run Project
1. Go to backend:
   ```bash
   cd Backend
   ```

2. Start backend & frontend:
   ```bash
   npm start
   ```
4. Open your browser:
   ```text
   Start-Process "http://localhost:5000/Dashboard/index.html"
